# תוכנית עסקית — AI Bookmarks SaaS | יעד: $10,000 MRR

<div dir="rtl">

> **תקציר מנהלים:** AI Bookmarks עוברת מהרחבת Chrome במודל BYOK (bring-your-own-API-key) ל-SaaS מלא עם backend מנוהל. המשתמש מתקין, נרשם — וה-AI עובד, בלי מפתח API משלו. המודל: Freemium עם מכסת AI חודשית, Pro ב-$6/חודש, Team ב-$10/משתמש/חודש. עם שוליים גולמיים של ~85%+ ועלות AI של פחות מ-$0.01 לסימנייה, הדרך ל-$10K MRR עוברת דרך ~1,400–1,700 מנויי Pro (או תמהיל Pro+Team) בתוך 12 חודשים, מונעת בעיקר על ידי לולאת ה-PLG של אוספים משותפים.

## 1. שדרוג המוצר: מ-BYOK ל-Hosted SaaS

### 1.1 למה BYOK לא מספיק

- פחות מ-5% ממשתמשי Chrome הממוצעים יודעים (או מוכנים) להנפיק Claude API key.
- BYOK חוסם מונטיזציה: אי אפשר לגבות על AI שהמשתמש משלם עליו בעצמו.
- אין נראות לשימוש → אין אנליטיקה, אין אופטימיזציית עלויות, אין funnel.

### 1.2 ארכיטקטורת היעד

| רכיב | היום (BYOK) | יעד (SaaS) |
|---|---|---|
| AI calls | ישירות מההרחבה עם מפתח של המשתמש | **Managed backend** (Cloud Functions / Cloudflare Workers) עם מפתח שלנו, מאחורי auth + מכסות |
| חשבון משתמש | אין | Firebase Auth (Google sign-in בקליק אחד) |
| נתונים | Chrome sync + Firebase (Firefox) | Firestore כמקור אמת + Chrome sync כ-cache מקומי |
| ממשק | ההרחבה בלבד | הרחבה + **Web dashboard** (ניהול אוספים, חיפוש, billing) |
| צוותים | אין | **Team workspaces**: אוספים משותפים לצוות, הרשאות, billing מרוכז |
| BYOK | ברירת מחדל | נשאר כאופציה ל-power users / enterprise (יתרון אמון) |

**עבודת פיתוח משוערת:** 6–8 שבועות לגרסת SaaS ראשונה (auth, proxy backend, metering, Stripe checkout, dashboard מינימלי).

| Tier | הכנסה/חודש | שימוש AI ממוצע בפועל | עלות AI | עלויות אחרות (Firebase, Stripe, infra) | רווח גולמי | שוליים |

## 4. הדרך ל-$10,000 MRR

### 4.1 תמהילים אפשריים

| מסלול | הרכב | MRR |
|---|---|---|
| A — Pro בלבד | ~1,667 מנויי Pro × $6 | $10,000 |
| B — תמהיל (המועדף) | 1,100 Pro × $6 + 35 צוותים × 10 seats ממוצע × $10... בפועל: 1,100×6 + 340 seats×10 | $6,600 + $3,400 = $10,000 |
| C — Annual-heavy | 1,400 Pro (60% שנתי) + 20 צוותים קטנים | ~$10,000 (תזרים מוקדם גבוה יותר) |

### 4.2 משפך המרה ריאליסטי (free→paid של 2–5%)

עובדים אחורה מ-1,500 משלמים (תמהיל B):

| שלב במשפך | שיעור | כמות נדרשת |
|---|---|---|
| התקנות מצטברות (Chrome Web Store + Firefox) | — | **~60,000** |
| Activation (נרשם + שמר 3 סימניות בשבוע הראשון) | 55% | 33,000 |
| Retained אחרי 30 יום | 45% מה-activated | ~15,000 MAU |
| Free → Paid | ~3% מהמותקנים / ~10% מה-retained | **~1,500 משלמים** |

**קצב התקנות נדרש:** ~5,000/חודש בממוצע שנתי — בר השגה עם שילוב של CWS SEO (הרחבות דומות בקטגוריה מגיעות ל-1–3K/חודש אורגני), לולאת האוספים, ו-2–3 spikes של השקות.

### 4.3 לולאות צמיחה PLG

1. **אוספים משותפים כרכישה ויראלית (הלולאה המרכזית):**
   - משתמש מפרסם אוסף → הלינק נצפה ברשתות/ניוזלטרים → צופה לוחץ **"Clone to my bookmarks"** → נדרש להתקין → הופך למשתמש שמפרסם אוספים.
   - יעד: viral coefficient K של 0.3–0.5 (כל 10 משתמשים מביאים 3–5). כל דף אוסף ציבורי = landing page מאונדקסת ב-Google (SEO מתחדש לבד).
   - האצה: "Collection of the week" בבלוג + שיתופי פעולה עם 10–20 curators/כותבי ניוזלטרים (Pro חינם תמורת אוסף ציבורי).
2. **Chrome Web Store SEO:** מיקוד במילות מפתח "AI bookmarks", "bookmark organizer", "Pocket alternative"; 50+ ביקורות 5★ ברבעון הראשון (בקשת ביקורת in-app אחרי "aha moment" — הסימנייה ה-10 שתויקה).
3. **השקת Product Hunt:** אחרי מעבר ל-SaaS. יעד: Top-5 של היום → 3–8K ביקורים, 1–2K התקנות, גל ביקורות.
4. **Content marketing:** 2 פוסטים/חודש (נכתבים ע"י ה-Content Agent — ראו [ai-agents-operations.md](./ai-agents-operations.md)): "Best Pocket alternatives 2026", "How I organized 3,000 bookmarks with AI", אוספי awesome-lists לכל נישת מפתחים.
5. **Weekly digest email:** סיכום AI שבועי של מה ששמרת — retention hook שמחזיר משתמשים ומזכיר לשדרג.

## 6. סיכום

- **המוצר קיים** — הסיכון הוא הפצה, לא טכנולוגיה.
- **הכלכלה עובדת** — עלות של פחות מ-$0.01 לסימנייה מול $6/חודש = שוליים של SaaS קלאסי.
- **המנוע הוא PLG** — כל אוסף משותף הוא salesperson; ה-clone loop הופך צריכה להפצה.
- **$10K MRR = ~1,500 משלמים = ~60K התקנות** — יעד אגרסיבי אך ריאלי בשוק שבו Pocket השאיר ואקום, בהינתן ביצוע עקבי של המשפך במשך 12 חודשים.
- התפעול השוטף מתוכנן לרוץ ברובו על ידי סוכני AI — ראו [ai-agents-operations.md](./ai-agents-operations.md).
